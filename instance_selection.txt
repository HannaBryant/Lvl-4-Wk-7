Break down the example instance name m5.2xlarge:
m - Refers to the instance family (General Purpose, Compute Optimized, Memory Optimized, Accelerated Computing, and Storage Optimized).
5 - Indicates the generation of te instance. AWS continually releases new gens with improved performance and efficiency.
2xlarge - Defines the size and capacity of the instance, which determines the number of vCPUs, RAM, and networking power.

1.) The Startup Web Server: You need a balanced mix of compute, memory, and networking for a small student or medium-sized project.
 Which instance category do you use, and which specific instance family/tier is available under the AWS Free Tier for learning?
General Purpose Instance & The 't' family.

2.)The High-Speed BI Reporting Engine: A Business Intelligence application needs to connect to direct databases,
 perform massive data imports, and manipulate data locally in real time.
 Which instance category optimizes this workflow, and why is high memory capacity critical here?
Memory Optimized Instance. High memory is critical here because there is large amounts of data being processed in real time.

3.)The High-Concurrency Ticketing Platform: A concert ticketing system experiences massive,
 sudden spikes with millions of simultaneous transactional requests when sales open.
 Which instance category provides the disk throughout and IOPS required to keep the system from crashing?
 Storage Optimized Instance.
